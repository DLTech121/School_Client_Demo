# DLTECH Academy Abuja — Homepage

## Package contents
- `index.html` — semantic page structure and homepage content
- `style.css` — all layout, typography, colour and responsive styling
- `script.js` — mobile navigation and active-section behaviour
- `assets/images/` — locally stored SVG illustration placeholders

## Preview
Extract the ZIP archive and open `index.html` in a modern browser. An internet connection is only needed to load the Google Fonts; the illustrations and core layout are local.

## Editing
- Update page text, links and section order in `index.html`.
- Change the colour variables at the top of `style.css`.
- Replace any SVG in `assets/images/` with your own campus/student photography. Keep the same filename, or update the corresponding `src` and CSS background URL.
- Replace the temporary DA crest/wordmark in the header and footer with the school's approved logo when supplied.

## Notes before launch
- The supplied contact details and statistics are presented as provided. Confirm all figures and contact details before publication.
- Admissions CTA opens an email draft addressed to `admission@dltechacademy.com`. A server-backed form will be required for website form submissions.
- This is a single-page homepage with in-page navigation. Separate About, Admissions, Teaching & Learning and Campus Life pages can be developed as the next phase.
- No AI branding, generator metadata or watermarks are included in the source files. SVG placeholders are clearly named and easy to replace.
